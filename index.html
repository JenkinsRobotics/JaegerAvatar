02 / AVATAR PACKS · FOUNDATION AVAILABLE

A character.
Many ways to perform.

The pack describes who the character is and how it appears. The controller supplies what it does next.

34 starter avatars bring together Mochi’s visual characters, JaegerAI’s personas and JaegerAgent’s assistant defaults. Source variants are preserved. The editor, playback and connections to existing apps are still in development.

03 / THE JAEGER ECOSYSTEM

Its own application.
A connected family.

Two planned ways to run the conversational experience, with one clear owner of each assistant session.

PRIMARY PATH · PLANNED

Run independently

Jaeger Avatar hosts the reusable JaegerAgent engine. Choose a character and talk, without running a separate JaegerAI application.

Jaeger Avatar↓Embedded JaegerAgent
OPTIONAL CONNECTION · PLANNED

Give your assistant a face

Connect to an existing JaegerAI instance. It keeps its conversation, memory and tools; Avatar gives that same assistant a visible presence.

04 / EARLY DEVELOPMENT

A clear direction.
An open starting point.

The avatar-pack foundation is in place: 34 avatars, 39 persona profiles and 38 representations, with import and validation tools. The application runtime is the work ahead.

Follow the repository for implementation. There is no installer yet, and the expression sketch above is not a running agent.
